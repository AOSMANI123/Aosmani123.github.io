# Changelog

## 0.1.0 — October 1, 2026

- Initial release: seven deterministic checks, CLI interface, web scorecard
- Checks: hedge/weasel words, passive voice, data density, adjective bloat, sentence length variance, buried lede detection, opening specificity
- CLI supports stdin, --file, and --json output modes
- Web demo implements the same rules client-side in vanilla JavaScript
- Precision-over-recall bar: flags only high-confidence findings
- Unit test suite covering all seven checks
