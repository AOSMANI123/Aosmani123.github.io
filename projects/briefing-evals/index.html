Briefing evals: does the AI make things up?

A small test suite for the failure I worry about most in AI-drafted briefings: a confident guess where the source was silent.

Type Independent workLanguage Python, no dependenciesCases 12, all fictionalView the code

Short version. I build systems that draft executive briefings. In a briefing, a guess is worse than a blank. This suite gives a drafter twelve fictional engagement requests, each with one trap, and scores two things: did it pull out what was there, and did it fill in what wasn't?

Why this matters

A briefing drafter that's right 95% of the time sounds great until you ask what the other 5% looks like. If it leaves a field blank, someone fills it in. If it invents a moderator's name or carries last year's date forward, that error can reach an executive's prep with no warning. The second failure is the one to measure.

The traps

How it's scored

The drafter returns JSON with nine fields. Each field is scored as correct, missed (said UNKNOWN when the answer was there), wrong, or fabricated (filled in when the source was silent). The scorer also flags any number in the output that doesn't appear in the source.

MetricQuestion it answers
Recall on known fieldsDid it pull out what was actually there?
Fabrication rateOf the fields that were missing, how many did it fill in anyway?

The experiment

Same cases, two prompts. The naive one says "fill in the briefing details." The other states the rules I actually use: only this event, UNKNOWN when it isn't stated, the forwarder isn't the requestor, copy numbers as written.

Hypothesis The naive prompt fills in missing fields. Explicit rules bring fabrication close to zero without hurting recall.

pip install anthropic

python3 evals.py --drafter anthropic --prompt prompts/naive.txt
python3 evals.py --drafter anthropic --prompt prompts/flag_gaps.txt

Limits

  • Twelve cases is a starting set, not a benchmark. Next is 50+ cases based on patterns from real requests, with every detail rewritten.
  • Matching is simple text containment, so it can't catch an invented venue added next to the correct city.
  • It checks the fact block, not the prose of the briefing.
